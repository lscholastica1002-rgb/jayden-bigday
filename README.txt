JAYDEN 21ST BIRTHDAY WEBSITE

GitHub Pages ready.

Files:
- index.html
- assets/ (all photos used by the site)

To publish:
1. Create/open your GitHub repository.
2. Upload index.html and the whole assets folder.
3. Go to Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save and wait for GitHub Pages to publish.

IMPORTANT: Keep the assets folder next to index.html. Do not rename or move the photos unless you also change their paths in index.html.

Music is intentionally not included. The player is a placeholder so no copyrighted audio is redistributed. You can later add a legally obtained audio file if you want.
